# Reel Minimal — 세로 스택 갤러리와 상세 보기

- 데모: [`reel-minimal/`](../reel-minimal/)
- 참고: [CMS Vertical Gallery](https://cmsverticalgallery.framer.website)의 세로 스택 구성. 사진 묶음·문구·서체는 새로 만들었다

## 구조

```txt
┌ 100dvh ───────────────────────────────────────────────┐
│ 머무는 빛                                 (01) / (06)  │
│                     ┌──────────┐                       │
│                     │  작은 판  │ (06)                  │
│ (05) 해 진 뒤        └──────────┘                       │
│ (06) 동굴      ┌────────────────────┐                  │
│ (01) 썰물      │     가운데 판       │                  │
│ (02) 밤 골목   └────────────────────┘                  │
│          (01)       ┌──────────┐                       │
│                     │  작은 판  │ (02)                  │
└───────────────────────────────────────────────────────┘
```

- 판은 모두 같은 크기(가로 62vw, 2.07 : 1)로 깔고 `clip-path: inset`으로 잘라 보인다. 가운데에서 멀수록 가로 63%, 세로 60%까지 줄어든다. 크기를 직접 바꾸지 않아 레이아웃 계산이 없다
- 판 사이 간격은 거리에 따라 구간별 선형으로 정한다. 가운데 판이 줄어드는 만큼 이웃이 다가와서 넘기는 중에도 간격이 14px로 유지된다
- 번호는 가운데 판이면 왼쪽 아래, 작은 판이면 오른쪽 아래에 보이고 거리에 따라 교차한다
- 왼쪽 목록도 같은 위치값으로 돈다. 현재 행이 커지고(15 → 28px) 진해진다. 끝없이 돌기 때문에 위아래 세 줄 밖은 흐려진다

## 동작

- 넘기기: 드래그(작은 판 높이+간격이 한 칸), 빠르게 튕기면 한 장, 휠 한 번에 한 장(600ms 잠금), ↑↓·PageUp/Down
- 목록 행이나 작은 판을 누르면 그 항목으로 간다. 지나가는 판도 차례로 커졌다 줄어든다
- 마우스를 판에 올리면 커서가 「보기」(가운데 판) 또는 「이동」(작은 판) 알약으로 바뀌고, 나머지 판은 70%로 흐려진다
- 가운데 판을 누르거나 Enter를 누르면 상세 보기가 열린다

## 상세 보기

- 전체 화면을 97% 불투명한 바탕색으로 덮고, 판 자리에서 사진이 커지며 화면 가운데로 온다(FLIP, 750ms). 비율이 같아서 찌그러지지 않는다
- 위: 「(04) / (06)」 번호와 닫기. 양옆: 이전·다음. 아래 왼쪽: 영문 이름, 제목, 한두 줄 설명. 아래 오른쪽: 촬영 시각과 사진 출처
- 사진 바꾸기: 새 사진이 진행 방향에서 `clip-path`로 열리고 이전 사진은 반대쪽으로 6% 밀린다(700ms). 글은 잠깐 사라졌다 올라온다
- 다음·이전: 버튼, 사진 클릭(다음), ←→, 휠·가로 스크롤, 터치 스와이프
- 닫기: 닫기 버튼, Esc. 닫으면 릴이 마지막으로 본 사진으로 맞춰지고 사진이 그 판 자리로 돌아간다
- 열려 있는 동안 릴은 `inert`, 포커스는 상세 보기 안에서만 돈다

## 색

영화 「네온 데몬」(2016) 한 장면에서 가져왔다. 푸르스름한 흰 스튜디오에 연분홍 꽃무늬 드레스 한 벌. 출처는 [Screen Musings의 스틸 페이지](https://screenmusings.org/movie/blu-ray/The-Neon-Demon/pages/The-Neon-Demon-112.htm)의 팔레트(`#eaf1f2` `#e3ebee` `#dae4e8` `#cfbaba` `#b99a9b` `#987878` `#887459`)다.

색 면적은 60-30-10 법칙으로 나눴다. 화면의 60%는 주색(바탕), 30%는 보조색, 10%는 포인트색이다.

| 비율 | 토큰 | 값 | 장면에서 | 쓰는 곳 |
|---|---|---|---|---|
| 60 주색 | `--bg` | `#eaf1f2` | 푸른 기가 도는 흰 스튜디오 | 바탕, 상세 보기 덮개(97%) |
| | `--plate` | `#dae4e8` | 그림자 진 바닥 | 사진이 뜨기 전 판 |
| 30 보조색 | `--mid` | `#7c6465` | 드레스 그림자(`#987878`를 읽히게 낮춤) | 설명, 번호 |
| | `--dim` | `#987878` | 드레스 그림자 | 다른 행, 안내 |
| | `--ink` | `#3a2e2f` | 같은 계열을 더 어둡게 | 제목, 현재 행 |
| 10 포인트 | `--accent` | `#a3535f` | 드레스의 장밋빛을 진하게 | 현재 번호, 상세 보기 영문 이름 |

- 장면 팔레트에 어두운 색이 없어서 글자색은 드레스 계열을 낮춰 만들었다. 바탕 대비 `--ink` 11.4 : 1, `--mid` 4.8 : 1, `--accent` 4.6 : 1, `--dim` 3.5 : 1
- 사진 갤러리라 화면 가운데는 사진이 차지한다. 비율은 사진을 뺀 나머지(바탕·글자·판)에 적용했다. 보조색은 면이 아니라 글자 체계 전체로 30%를 맡는다
- 포인트색은 두 곳에만 쓴다. 장면에서도 진한 분홍은 드레스 무늬 일부뿐이다

## 서체

| 역할 | 서체 |
|---|---|
| 한글 전부(목록, 제목, 설명, 버튼, 안내) | 고운바탕(Gowun Batang) 400 / 700 |
| 번호, 영문 이름, 촬영 정보 | EB Garamond. 영문 이름은 이탤릭. 숫자는 `lining-nums tabular-nums` |

- 색이 연하고 공기가 많은 화면이라 굵은 고딕보다 획이 가는 바탕체가 어울린다. 고운바탕은 획 끝이 둥글어 연분홍 계열과 잘 맞는다
- 라틴 서체는 [Open Foundry](https://open-foundry.com/fonts/eb-garamond)에서 골랐다. 고운바탕과 같은 붓 기반 세리프라 한글과 섞여도 결이 맞고, 이탤릭이 부드러워 영문 이름에 어울린다. 디돈 계열(Bodoni Moda)은 획 대비가 커서 작은 번호가 고운바탕보다 날카로워 보였다
- 모노 서체·대문자·넓은 자간은 걷어냈다. 한글과 섞이면 기계적으로 보였다
- 둘 다 Google Fonts, SIL OFL이라 상업 작업에 쓸 수 있다

## 바꿔 쓸 곳

- `ITEMS`: 사진(`photo`), 한글·영문 이름, 설명, 촬영 시각(`time`), 출처(`credit`)
- `measure()`: 판 크기(`.62`, `1000`, `.44`), 작은 판 비율(`.63`, `.6`), 간격(`G`), 가운데 위치(`cx`)
- `loop()`의 `.1`: 따라붙는 속도
- `:root`: 바탕(`--bg`), 덮개(`--veil`), 글자색, 포인트색(`--accent`)

## 모바일(720px 이하)

- 판은 화면 너비에 3 : 2, 화면 위쪽 42%에 둔다. 번호는 숨기고 목록은 아래 세 줄만 보인다. 목록 뒤에 바탕색 그라디언트를 깔아 사진과 겹치지 않게 한다
- 상세 보기의 이전·다음은 맨 아래로 내리고 촬영 정보는 숨긴다
